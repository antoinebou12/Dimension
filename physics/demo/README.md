# physics-demo

3D demo of PBD physics: particles and rigid bodies (winit + WASM).

## Controls

- **Left-drag** — Orbit camera around the scene.
- **Ctrl + drag** — Pan camera (move view target in the view plane).
- **Mouse wheel** — Zoom in/out.
- **Drop object** (UI button) — Spawn a new body above the ground; it falls and collides with the plane and other bodies. Spawning is capped at 64 bodies.
