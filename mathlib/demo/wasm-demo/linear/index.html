Storage

    
1 Column vs Row Major

    
Column-major: elements in same column are consecutive. mathlib uses column-major (like BLAS, Fortran, MATLAB). In matrix multiply and matvec, rows of A are used as dot-product vectors with columns of B or with v; columns of A are the vectors that get scaled and summed in A×v. Storage order does not change the math, only how the same numbers are laid out in a flat array.

Sparse

    
7 Sparse formats (CSR, CCS, COO)

    
For matrices with few non-zeros, sparse storage saves memory and can speed up operations. CSR (Compressed Sparse Row) stores row_ptr (start index per row), col_ind (column index of each entry), and values. CCS is column-wise; COO is a list of (row, col, value). mathlib provides CRS and other formats.
